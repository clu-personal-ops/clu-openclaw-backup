## Source and runtime boundary

Canonical **technical knowledge** now lives here. Published executable files still
represent the historical sanitized review snapshot, not all newer private development.
The active development checkout remains the existing job-pipeline-planner-pilot;
its AUTONOMY_CHECKPOINT.json owns exact resume state. Do not run or overwrite private
accepted state from the review snapshot. This is one system, not two architectures.
Later code publication must be scoped and sanitized, not a wholesale private-tree push.

At significant reviews, the host reads these docs and supplies relevant evidence
in bounded planner requests. README links do not automatically inject model context.
Workers receive only their task contracts. Record new decisions and status here;
consult original Notion/issues only for a specific unresolved provenance question.
Do not routinely rediscover already consolidated decisions there.
